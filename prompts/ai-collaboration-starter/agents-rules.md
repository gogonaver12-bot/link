# Shared project rules

- 이 저장소만 작업 범위로 삼는다. 다른 프로젝트 및 전역 설정을 변경하지 않는다.
- 작업 전에 현재 경로, git status, branch, 필요한 지침과 진입점을 확인한다.
- 사용자 요청 범위만 최소 수정하고 필요한 검증만 실행한다. 유료 API 호출은 하지 않는다.
- main 폴더는 통합용이다. Codex는 codex 폴더/브랜치, Claude는 claude, Gemini는 gemini를 사용한다.
- 각 도구는 자기 worktree에서만 수정한다. 다른 도구의 브랜치로 전환하거나 다른 worktree의 파일을 수정하지 않는다.
- 시작 전에 맡을 작업과 파일 범위를 정한다. 동일 파일 동시 작업은 피하고 필요한 경우 사용자에게 조율을 요청한다.
- 병렬 작업 결과는 커밋과 diff로 전달한다. 자동 병합, force push, reset --hard, 타인 변경 폐기는 하지 않는다.
- 다른 도구의 작업 반영은 사용자 요청 범위에서 커밋을 검토한 뒤 병합한다. 미커밋 변경이 있으면 먼저 보존한다.
- 종료 시 handoff/<도구명>.md에 목표, 변경 파일, 검증 결과, 미완료, 전달 커밋을 간결하게 기록한다.
- .env, 키, 쿠키, 인증 파일, 고객 원본 데이터는 커밋하지 않는다. push 전 staged diff와 파일 목록을 확인한다.
- AI끼리 대화나 기억이 자동 공유된다고 주장하지 않는다. 공유되는 것은 Git에 반영된 파일과 커밋이다.
- 답변은 기본 한국어 3~6줄. 예상 사용량을 낮음/보통/높음으로 먼저 안내한다.
