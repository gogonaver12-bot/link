# 엑셀 함수 몰라도 챗GPT로 매출 정산하고 칼퇴하는 법

매달 말일마다 돌아오는 매출 정산과 복잡한 엑셀 파일 때문에 머리가 아프신가요? 이제 수많은 함수와 피벗테이블 문법을 억지로 외우느라 포털 검색창을 전전할 필요가 없습니다. 챗GPT를 전담 엑셀 과외 선생님으로 활용해 칼퇴를 앞당기는 실전 데이터 가공법을 정리했습니다.

---

### 1. 엑셀 함수를 외우지 않아도 되는 이유
우리가 엑셀을 어렵게 느끼는 이유는 "A열과 B열을 비교해 줘"라는 평소의 생각을 엑셀 함수 문법으로 변환하는 과정이 낯설기 때문입니다. 챗GPT는 우리가 쓰는 일상 언어를 엑셀의 언어로 정확하게 번역해 줍니다. 하고 싶은 목적만 명확히 말하면, 1초 만에 최적의 수식이나 해결책을 찾아줍니다.

### 2. 피벗테이블과 데이터 요약, 프롬프트 하나로 해결하기
방대한 매출 데이터를 받아 피벗테이블을 어떻게 만들어야 할지 막막할 때는 챗GPT에 데이터 구조를 설명하고 요약을 요청해 보세요.

**[추천 프롬프트 예시]**
> "너는 10년 차 엑셀 전문가야. [날짜, 지점, 품목, 수량, 단가, 담당자] 구조의 매출 데이터를 가지고 각 지점별, 품목별 총 매출액을 요약하려고 해. 피벗테이블을 만드는 단계별 방법과 엑셀 수식을 알려줘."

*이때 실제 데이터를 몇 줄 복사해서 붙여넣되, 사내 기밀이나 개인정보는 반드시 익명화(예: 직원A)하여 입력하는 보안 원칙을 지켜야 합니다.*

### 3. VLOOKUP·XLOOKUP 에러 탈출하기
인증 오류와 `#N/A` 에러를 자주 내는 VLOOKUP이나 XLOOKUP 함수도 이제 직접 쓰지 마세요. 챗GPT에 상황을 그대로 털어놓으면 됩니다.

"시트1의 상품코드에 맞는 판매량을 시트2의 가격표에서 가져오고 싶어"라고 입력하면, 챗GPT가 `=XLOOKUP(A2, 시트2!A:A, 시트2!C:C)` 같은 정확한 수식을 짜줍니다. 우리는 그저 복사해서 엑셀에 붙여넣기만 하면 됩니다.

### 4. 복잡한 텍스트 데이터 청소하기
이름, 직급, 부서가 `김철수_대리_서울본부`처럼 한 칸에 뭉쳐 있는 1,000개의 데이터를 쪼갤 때도 챗GPT가 유용합니다. 텍스트 나누기 기능, 플래시 필드, 혹은 함수 중 가장 쉬운 방법을 골라 단계별로 안내받을 수 있어 수동 작업 시간을 획기적으로 줄여줍니다.

---

### 💡 칼퇴를 앞당기는 엑셀 & 챗GPT 3원칙
1. 함수 문법을 억지로 외우지 않고 챗GPT에 자연어로 질문한다.
2. 사내 기밀 및 개인정보는 반드시 익명화하여 입력한다.
3. 데이터 구조와 원하는 목적을 명확하게 설명한다.
