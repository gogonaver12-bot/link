## 3. 1차 라우터 구현 - 메인 유료 API 연동 및 호출

마이크로SaaS를 운영하면서 가장 먼저 마주하는 공포는 'API 비용 폭탄'과 '서비스 다운타임'이다. 사용자가 몰렸는데 OpenAI나 Anthropic 서버가 응답하지 않거나, 토큰 폭탄을 맞아 하루아침에 적자가 나는 상황을 막아야 한다. 

이번 장에서는 1차 라우터의 핵심인 **메인 유료 API 연동, 타임아웃 및 레이트 리밋(Rate Limit) 예외 처리, 그리고 비동기(Async) 기반의 응답 속도 최적화** 코드를 완성한다. 복사해서 바로 쓸 수 있는 실전 프로덕션 레벨의 파이썬(Python) 코드를 제공한다.

---

### 1. 비동기 환경 설정 및 패키지 설치

속도가 경쟁력인 마이크로SaaS에서 동기(Sync) 방식으로 API를 호출하면 대기 시간 동안 서버 자원이 낭비된다. `httpx`와 공식 비동기 SDK를 사용하여 병렬 처리가 가능하도록 환경을 세팅한다.

```bash
pip install openai anthropic httpx python-dotenv pydantic
```

프로젝트 루트에 `.env` 파일을 만들고 API 키를 입력한다.
```env
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
```

### 2. 메인 유료 API 연동 및 예외 처리 라우터 코드

아래 코드는 OpenAI를 메인으로 호출하되, **레이트 리밋(429), 서버 에러(5xx), 그리고 타임아웃(Timeout)** 발생 시 예외를 정확히 캐치하여 다음 단계(폴백)로 넘길 준비를 하는 1차 라우터 모듈이다.

```python
# router.py
import os
import asyncio
from openai import AsyncOpenAI, RateLimitError, APITimeoutError, APIConnectionError
from anthropic import AsyncAnthropic
from dotenv import load_dotenv

load_dotenv()

# 비동기 클라이언트 초기화 (connection pool 최적화)
openai_client = AsyncOpenAI(api_key=os.getenv("OPENAI_API_KEY"))
anthropic_client = AsyncAnthropic(os.getenv("ANTHROPIC_API_KEY"))

async def call_openai_main(prompt: str, model: str = "gpt-4o-mini") -> str:
    """
    OpenAI 메인 API 호출 함수 (타임아웃 및 예외 처리 포함)
    """
    try:
        # 타임아웃을 5초로 설정하여 무한 대기 방지
        response = await asyncio.wait_for(
            openai_client.chat.completions.create(
                model=model,
                messages=[{"role": "user", "content": prompt}],
                temperature=0.7,
            ),
            timeout=5.0 
        )
        # 성공 로그 수집 (모니터링 기초)
        print(f"[LOG] SUCCESS: OpenAI ({model}) responded.")
        return response.choices[0].message.content

    except asyncio.TimeoutError:
        print("[LOG] WARNING: OpenAI API Timeout (5s exceeded). Switching to fallback...")
        raise 
    except RateLimitError:
        print("[LOG] WARNING: OpenAI Rate Limit Hit (429). Switching to fallback...")
        raise
    except (APIConnectionError, APITimeoutError) as e:
        print(f"[LOG] ERROR: OpenAI Connection/API Error: {e}. Switching to fallback...")
        raise
    except Exception as e:
        print(f"[LOG] CRITICAL: Unexpected OpenAI Error: {e}")
        raise

async def call_anthropic_main(prompt: str, model: str = "claude-3-5-sonnet-20241022") -> str:
    """
    Anthropic 메인 API 호출 함수 (필요시 대체 메인으로 사용)
    """
    try:
        response = await asyncio.wait_for(
            anthropic_client.messages.create(
                model=model,
                max_tokens=1024,
                messages=[{"role": "user", "content": prompt}]
            ),
            timeout=5.0
        )
        print(f"[LOG] SUCCESS: Anthropic ({model}) responded.")
        return response.content[0].text
    except Exception as e:
        print(f"[LOG] ERROR: Anthropic API Error: {e}")
        raise
```

### 3. 비동기 처리(Async)를 통한 성능 최적화 검증

마이크로SaaS는 동시 다발적인 유저 요청을 처리해야 한다. 위에서 만든 라우터가 비동기로 원활히 작동하는지 테스트하는 스크립트다.

```python
# test_router.py
import asyncio
from router import call_openai_main

async def main():
    prompts = [
        "마이크로SaaS 아이디어 3가지 추천해줘.",
        "파이썬 비동기 프로그래밍의 장점을 3줄로 요약해줘.",
        "LLM API 비용을 절감하는 가장 현실적인 방법은?"
    ]
    
    # asyncio.gather를 이용해 동시에 3개의 요청 발사 (병렬 처리)
    tasks = [call_openai_main(p) for p in prompts]
    results = await asyncio.gather(*tasks, return_exceptions=True)
    
    for i, res in enumerate(results):
        if isinstance(res, Exception):
            print(f"Request {i+1} Failed: {res}")
        else:
            print(f"Request {i+1} Result: {res[:50]}...\n")

if __name__ == "__main__":
    asyncio.run(main())
```

### 4. 성공/실패 로그 및 모니터링 기초

1인 개발자에게 복잡한 데이터dog 같은 모니터링 툴은 과하다. 초기에는 **구조화된 로그(Structured Logging)**를 통해 터미널이나 파일에 에러 원인을 정확히 남기는 것만으로도 충분하다.

위 코드에서 적용된 로그 수집 원칙은 다음과 같다:
1. **성공 여부 (`SUCCESS` / `WARNING` / `ERROR`)**: 어떤 모델이 정상 작동했는지, 어떤 에러 때문에 폴백으로 전환되는지 직관적으로 파악.
2. **예외 세분화**: 단순 `except Exception:`으로뭉개지 않고, `RateLimitError`(비용/쿼리 초과)와 `TimeoutError`(서버 지연)를 분기하여 라우팅 전략에 즉시 반영.
