### 2. PyPI 및 npm 배포 자동화

배포 과정은 복잡할 필요 없다. 터미널 명령어 몇 번이면 끝난다.

#### Python 패키지 (PyPI) 빌드 및 배포
```bash
# 1. 빌드 도구 설치
pip install --upgrade build twine

# 2. 패키지 빌드 (dist/ 폴더 생성)
python -m build

# 3. TestPyPI 업로드 테스트 (선택 사항)
python -m twine upload --repository testpypi dist/*

# 4. 실제 PyPI 업로드
python -m twine upload dist/*
```

#### Node.js 패키지 (npm) 빌드 및 배포
```bash
# 1. npm 로그인 확인
npm login

# 2. TypeScript 컴파일
npm run build

# 3. 퍼블릭 배포
npm publish --access public
```

### 3. API 키 발급 및 사용량 추적 미들웨어 구현

마이크로SaaS 운영을 위해 사용자의 API 호출 횟수와 토큰 사용량을 추적하는 미들웨어를 만든다. (Node.js/Express 기준)

**[코드] 사용량 추적 미들웨어 (`middleware.ts`)**
```typescript
import { Request, Response, NextFunction } from 'express';

// 간단한 인메모리 스토어 (실무에서는 Redis 또는 PostgreSQL 사용)
const usageStore: Record<string, { count: number; limit: number }> = {
  'test_api_key_123': { count: 0, limit: 100 }
};

export function usageTrackingMiddleware(req: Request, res: Response, next: NextFunction) {
  const apiKey = req.headers['x-api-key'] as string;

  if (!apiKey || !usageStore[apiKey]) {
    return res.status(401).json({ error: 'Invalid or missing API Key' });
  }

  const userUsage = usageStore[apiKey];

  if (userUsage.count >= userUsage.limit) {
    return res.status(429).json({ error: 'API usage limit exceeded' });
  }

  // 사용량 증가
  userUsage.count += 1;
  req.body.remainingQuota = userUsage.limit - userUsage.count;
  
  next();
}
```

### 4. Next.js 기반 간단한 사용량 대시보드 웹 UI

사용자가 자신의 API 키 잔여량을 확인하고 모니터링할 수 있는 미니멀한 대시보드를 만든다.

**[코드] Next.js 대시보드 페이지 (`app/dashboard/page.tsx`)**
```tsx
'client'
import { useState, useEffect } from 'react';

export default function Dashboard() {
  const [stats, setStats] = useState({ count: 0, limit: 100, remaining: 100 });
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    // 실제 구현에서는 API 엔드포인트에서 데이터를 가져옴
    setTimeout(() => {
      setStats({ count: 42, limit: 100, remaining: 58 });
      setLoading(false);
    }, 500);
  }, []);

  if (loading) return <div className="p-8">로딩 중...</div>;

  return (
    <main className="p-8 max-w-xl mx-auto font-sans">
      <h1 className="text-2xl font-bold mb-6">LLM 라우터 사용량 대시보드</h1>
      
      <div className="bg-white border rounded-lg p-6 shadow-sm space-y-4">
        <div>
          <p className="text-sm text-gray-500">API 키 상태</p>
          <p className="font-mono text-sm bg-gray-100 p-2 rounded mt-1">test_api_key_123</p>
        </div>

        <div className="grid grid-cols-2 gap-4 pt-4 border-t">
          <div>
            <p className="text-sm text-gray-500">사용한 요청 수</p>
            <p className="text-2xl font-semibold text-blue-600">{stats.count} 회</p>
          </div>
          <div>
            <p className="text-sm text-gray-500">잔여 할당량</p>
            <p className="text-2xl font-semibold text-green-600">{stats.remaining} 회</p>
          </div>
        </div>

        <div className="pt-4">
          <div className="w-full bg-gray-200 rounded-full h-2.5">
            <div 
              className="bg-blue-600 h-2.5 rounded-full" 
              style={{ width: `${(stats.count / stats.limit) * 100}%` }}
            ></div>
          </div>
        </div>
      </div>
    </main>
  );
}
```
