## 1. 1장. 챗GPT와 친해지기: 초보자를 위한 기본 개념과 가입  

### 1-1. 챗GPT가 뭔가요?  
- **AI 언어 모델**: 방대한 텍스트 데이터를 학습해 자연스러운 대화를 생성합니다.  
- **업무 도우미**: 자료 요약, 이메일 초안 작성, 일정 정리, 코드 디버깅 등 다양한 작업을 텍스트 명령 하나로 처리할 수 있습니다.  

### 1-2. 무료 버전 vs. Plus(유료) 완벽 비교  

| 항목 | 무료 버전 | ChatGPT Plus (월 $20) |
|------|-----------|-----------------------|
| **사용 제한** | 하루 25 회(시간당 3 회) 정도, 트래픽이 많을 때 대기열 발생 | 우선 순위 접근, 대기열 거의 없음 |
| **응답 속도** | 일반 서버 부하 시 느려짐 | 고속 서버 전용, 평균 2‑3 초 |
| **모델 버전** | GPT‑3.5 (기본) | GPT‑4 (더 높은 정확도·복잡한 논리) |
| **업무 활용** | 간단한 질문·요약·아이디어 도출 | 복합 문서 작성·고급 데이터 분석·프로그래밍 지원 |
| **API 연동** | 제한적(공식 웹만) | API 키 제공, 외부 툴과 연동 가능 |

> **핵심 포인트**: 초보자는 무료 버전으로 충분히 체험해보고, 업무 복잡도가 ↑하면 Plus로 전환하면 비용 대비 효율이 크게 올라갑니다.  

### 1-3. 회원가입부터 첫 화면 적응까지 1분 가이드  

1️⃣ **오픈AI 홈페이지**([https://chat.openai.com](https://chat.openai.com))에 접속 → “Sign up” 클릭  
2️⃣ **이메일**(또는 Google·Microsoft 계정) 입력 → 인증 메일 확인 → 비밀번호 설정  
3️⃣ **프로필 설정**: 이름(예: “김대리”)과 간단한 프로필 사진(선택) 입력 → “Continue”  
4️⃣ **첫 화면**:  
- 좌측 상단에 **새 대화** 버튼  
- 중앙에 **프롬프트 입력창** (“Ask me anything…”)  
- 우측에 **이전 대화 기록**(스크롤)  

> **팁**: 화면 오른쪽 위 ‘Settings → Theme’에서 ‘Dark mode’를 켜면 눈 피로가 감소합니다.  

### 1-4. AI에게 원하는 답을 얻는 기본 대화 원칙  

| 원칙 | 설명 | 예시 |
|------|------|------|
| **구체적** | 질문을 구체적으로 할수록 정확한 답변이 온다. | ❌ “보고서 작성 도와줘” → ✅ “5월 매출 보고서 초안을 300자 이내로 요약해줘” |
| **맥락 제공** | 이전 대화 흐름을 이어주면 일관된 답변 가능. | “앞서 만든 표에 ‘전년 대비 증가율’ 컬럼을 추가해줘.” |
| **형식 지정** | 원하는 출력 형식을 명시한다. | “표 형태로, 열은 ‘날짜’, ‘매출’, ‘증가율’ 로 출력해줘.” |
| **제한 조건** | 글자 수, 톤, 언어 등을 제한한다. | “300자 이하, 친근한 톤, 한국어로 작성해.” |

### 1-5. 바로 복붙해서 쓸 수 있는 프롬프트 템플릿  

```text
[작업 종류] + [구체적 목표] + [출력 형식] + [제한 조건]

예시 1)  
"5월 팀 회의 안건을 5개 항목으로 정리하고, 각각 50자 이하로 요약해. 표 형태로 보여줘."

예시 2)  
"신제품 소개 이메일 초안을 작성해. 친근하고 설득력 있게, 200자 이내, 제목은 '새로운 경험을 만나보세요'로 시작해."

예시 3)  
"지난 3개월 매출 데이터를 기준으로 전년 대비 증감률을 계산하고, 그래프 코드(Plotly)로 시각화해줘."
```

### 1-6. 체크리스트 – 첫 사용 전 확인 사항  

- [ ] 이메일 인증 완료 → 로그인 가능 여부 확인  
- [ ] 프로필에 이름·사진 설정 (팀 채팅에 활용 시 편리)  
- [ ] ‘Settings’에서 기본 언어(한국어)와 테마(다크/라이트) 선택  
- [ ] 무료 버전 사용량 제한(시간당 3 회) 파악 → 필요 시 Plus 업그레이드 계획 수립  
- [ ] 기본 프롬프트 템플릿 3개 저장(예: 회의 안건, 이메일 초안, 데이터 시각화)  

### 1-7. 실전 예시 – 5분 안에 회의록 요약하기  

1️⃣ **원본 텍스트** 복사  
```
[회의 내용] 2024년 3월 15일, 마케팅팀 회의. 주요 안건은 신제품 런칭 일정, SNS 광고 예산, 고객 피드백 정리 등...
```
2️⃣ **프롬프트 입력**  
```
위 회의 내용을 4개의 핵심 포인트로 정리하고, 각 포인트를 30자 이하로 요약해. 표 형태(항목/내용)로 보여줘.
```
3️⃣ **결과**  
| 항목 | 내용 |
|------|------|
| 일정 | 신제품 5월 1일 출시 |
| 예산 | SNS 광고 2천만원 배정 |
| 피드백 | 고객 만족도 85% |
| 다음 단계 | 프로토타입 테스트 진행 |

> **활용 팁**: 회의 직후 이 템플릿을 복사해 붙이고 바로 요약하면, 회의록 작성 시간을 70% 이상 단축할 수 있다.
