   - **에러 내용**: `RuntimeError: 대본 JSON을 3번 받아도 형식이 깨짐: Expecting value: line 27 column 14 (char 975)`

2. **코드 경로 추적**
   - `mother/story.py`의 `episode` 함수(147행) 내부에서 `_json` 함수(62행)를 호출함.
   - `_json` 함수 내부에서 LLM 응답을 받아 JSON으로 파싱하려는 로직이 존재하며, 형식 오류 시 최대 3번까지 재시도 후 실패 시 `RuntimeError`를 발생시킴.
3. **확인된 사실 vs 추측**
   - **[사실]**: 파서가 기대하는 JSON 포맷과 LLM이 생성한 응답의 27번째 줄 근처(`char 975`)에 문법적 오류(예: 따옴표 누락, 쉼표 오류, 마크다운 코드블록 포함 등)가 있어 `json.loads`가 실패함.
   - **[추측]**: LLM 프롬프트에 엄격한 JSON 출력 제약(예: 마크다운 백틱 제거 지시, JSON 외 텍스트 금지 등)이 누락되었거나 약함.
