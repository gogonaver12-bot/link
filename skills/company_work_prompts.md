## 0. 기본 설정 (대화 시작 시 1회)
```
너는 내 업무 비서야. 규칙:
1) 답변은 핵심만 요약, 표/불릿 위주
2) 모르는 건 추측하지 말고 "확인 필요"라고 표시
3) 내가 다음에 필요할 것 같은 것(체크리스트, 다음 할 일)을 미리 제안
4) 질문이 필요하면 쉬운 말로 최대 3개만
내 직무: [예: 마케팅 / 영업 / 인사 / 개발]
회사/업종: [예: 쇼핑몰, IT 스타트업]
```

## 1. 이메일 작성
```
아래 내용으로 업무 이메일 써줘.
- 받는 사람: [거래처 담당자 / 팀장님]
- 목적: [일정 조율 / 견적 요청 / 사과 / 독촉]
- 핵심 내용: [내용]
- 톤: [정중 / 간결 / 단호]
제목 3개 + 본문 1개, 300자 이내로.
```

## 2. 회의록 정리
```
아래 회의 메모를 회의록으로 정리해줘.
형식: ①회의 요약(3줄) ②결정사항 ③할 일(담당자/마감일 표) ④다음 회의 안건
메모: [여기에 메모/녹취 붙여넣기]
```

## 3. 보고서 / 주간보고
```
아래 내용으로 [주간/월간] 업무보고 만들어줘.
형식: 이번 주 한 일 / 성과(숫자) / 이슈·리스크 / 다음 주 계획
윗사람이 30초 안에 읽을 수 있게 요약 먼저.
내용: [업무 내용]
```

## 4. 기획서 초안
```
[주제] 기획서 초안 써줘.
목차: 배경 → 목표(KPI) → 타깃 → 실행 방안 → 일정 → 예산 → 기대효과 → 리스크
각 항목 3~5줄. 빈 정보는 [확인 필요]로 표시.
```

## 5. 엑셀 / 데이터
```
엑셀에서 [하고 싶은 것: 예) 거래처별 월 매출 합계] 하고 싶어.
데이터 구조: A열 [날짜], B열 [거래처], C열 [금액]
수식 알려주고, 단계별로 쉽게 설명해줘. 피벗테이블 방법도 같이.
```

## 6. 문서 요약
```
아래 문서를 요약해줘.
①한 줄 요약 ②핵심 5개 ③내가 해야 할 일 ④주의할 점(숫자·기한·조건)
[문서 붙여넣기]
```

## 7. 보고/설득 문장 다듬기
```
아래 글을 [팀장님/임원] 보고용으로 다듬어줘.
결론 먼저, 근거는 짧게, 비즈니스 말투로. 수정 전/후 비교표도.
[원문]
```

## 8. 업무 우선순위 정리
```
오늘 할 일 목록이야. 긴급/중요 기준으로 우선순위 매기고
시간대별 일정표(9시~18시)로 짜줘. 미뤄도 되는 건 따로 표시.
[할 일 목록]
```

## 9. 고객 응대 / 클레임
```
고객 클레임 답변 써줘.
상황: [불만 내용]
회사 입장: [가능한 보상/불가 사항]
공감 → 사과 → 해결책 → 재발방지 순서, 3가지 버전(정중/간결/문자용).
```

## 10. 발표 자료 (PPT)
```
[주제]로 [10]장짜리 발표자료 구성 짜줘.
장마다: 제목 / 핵심 메시지 1줄 / 넣을 내용 3개 / 추천 그래프·이미지
마지막에 예상 질문 5개 + 답변.
```

## 11. 면접 / 채용
```
[직무] 채용 공고문 써줘 (주요업무/자격요건/우대사항).
그리고 면접 질문 10개 + 각 질문에서 확인할 포인트도.
```

## 12. 협상 / 거절
```
[상대]에게 [요청 내용]을 정중하게 거절(또는 조건 협상)하는 메시지 써줘.
관계는 유지하고 대안 1~2개 제시.
```

## 13. 업무 매뉴얼 만들기
```
아래 업무 과정을 신입도 따라할 수 있는 매뉴얼로 만들어줘.
단계별 번호, 주의사항, 자주 하는 실수, 체크리스트 포함.
[업무 과정 설명]
```

## 14. 아이디어 브레인스토밍
```
[문제/목표]에 대한 아이디어 10개 줘.
각각 비용(상/중/하), 효과(상/중/하), 실행 난이도 표로 정리하고
바로 해볼 만한 TOP 3 추천.
```

## 꿀팁
- 결과가 별로면: "더 짧게" / "표로" / "초등학생도 알게" / "3가지 버전으로"
- 회사 기밀·개인정보(주민번호, 고객 연락처, 계약 금액 등)는 넣지 말 것
- 숫자·법률·세금 내용은 반드시 직접 확인
