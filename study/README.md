# 📚 쉬운 공부방

초보자용 공부 프로그램. 지금은 **해부학 기초(6단원)** + **신경계(7단원)**.
각 단원 = 비유 → 쉬운 설명 → 그림(SVG) → 용어 → 영상 → 퀴즈 → 참고 교과서·논문.

## 실행
`index.html` 을 브라우저로 열면 끝 (설치 필요 없음). 진도는 브라우저에 자동 저장.

## 새 과목 추가 (예: 생리학, 약리학)
1. `subjects/_template.js` 복사 → `subjects/새과목.js`
2. 내용 채우기
3. `index.html` 에 `<script src="subjects/새과목.js"></script>` 한 줄 추가

## 영상·그림
- 영상: `video.youtubeId` 에 유튜브 영상 ID를 넣으면 페이지 안에서 재생. 비우면 검색 버튼만 표시.
- 그림: SVG 직접 작성 또는 `images/` 폴더에 이미지 넣고 `<img>` 사용.
