# 회사 도우미 (전기·PLC 업무 통합 프로그램)

## 설치 (아버지 PC)
1. GitHub 저장소 → **Releases** → 최신 `OfficeHelper.exe` 받기 → 더블클릭 (설치 없음)
2. 처음 한 번 **⚙ 회사 정보 설정**에 회사명·전화번호 입력 → 견적서·PPT에 자동으로 들어감
3. 결과물은 `내 폴더\회사도우미\결과물\` 에 저장 (프로그램의 **결과 파일 열기** 버튼으로 바로 열림)

## 기능
| 기능 | 하는 일 |
|---|---|
| 📊 PPT 자동 만들기 | `# 제목` / `- 항목` / `\| 표 \|` / `그림: 경로` 로 쓰면 16:9 발표자료 완성. AI 체크하면 주제만으로 내용 작성 |
| 💰 견적서 만들기 | 품목 붙여넣기 → 엑셀 견적서 (한글 금액, 부가세·이윤 자동, 엑셀에서 고쳐도 자동 재계산) |
| ⚡ 전기 계산기 | 부하전류, 전압강하 기준 전선 굵기, 차단기 참고값, 역률개선 콘덴서 (참고용) |
| 🔌 PLC 모니터 | Modbus TCP(LS·미쓰비시·지멘스 공통) / 미쓰비시 MC로 값 읽기 + 엑셀 기록. **쓰기 기능 없음(안전)** |
| 📝 작업일지 | 입력할 때마다 월별 엑셀에 한 줄씩 누적 |

## 기능 추가·업그레이드
- **새 기능** = `modules/_template.py` 복사해 파일 하나 작성 → `office_suite/modules/` 에 넣고 커밋하면 GitHub가 새 exe 자동 빌드
- exe 사용 중이면 `회사도우미\plugins\` 폴더에 .py 파일만 넣고 **도움말 → 기능 다시 불러오기** (재설치 불필요)
- 같은 `KEY`로 만들면 기존 기능을 덮어써서 업그레이드
- 소스 실행: `python -m office_suite` (GUI) · `python -m office_suite list` · `python -m office_suite run ppt title=보고서`
